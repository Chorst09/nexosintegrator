# 🚀 Guia Rápido - Novas Funcionalidades

## 📊 Exportar Quadro Kanban para PDF

### Passo a Passo:

1. **Acesse o Quadro**
   - Menu: Gestão de Projetos → Visualizar → Quadros

2. **Localize a Toolbar**
   - No topo da página, você verá uma nova barra com informações

3. **Exporte ou Imprima**
   - **Exportar PDF:** Clique no botão laranja "Exportar PDF"
   - **Imprimir:** Clique no botão "Imprimir"

4. **Resultado**
   - PDF será baixado automaticamente em formato paisagem
   - Nome: `quadro-kanban-2026-09-03.pdf`

## 🎨 Acessar Diagramas Salvos (Novo Layout!)

### O que mudou?
❌ **ANTES:** Painel lateral fixo ocupando espaço no desenho  
✅ **AGORA:** Modal flutuante com cards visuais

### Como usar:

1. **Acesse Diagramas**
   - Menu: Gestão de Projetos → Quadros → Diagrama de Arquitetura

2. **Abra a Lista**
   - Clique no botão **"📁 Diagramas Salvos"** no topo
   - O número ao lado mostra quantos diagramas você tem

3. **Visualize seus Diagramas**
   - Modal abre com cards organizados
   - Cada card mostra:
     - Nome do diagrama
     - Cliente e projeto
     - Data da última edição
     - Badge se estiver editando/visualizando

4. **Ações Disponíveis**
   - **👁️ Visualizar:** Abre em modo somente leitura
   - **✏️ Editar:** Abre para edição
   - **🗑️ Excluir:** Remove o diagrama (pede confirmação)

5. **Fechar o Modal**
   - Clique no **X** no canto superior direito
   - Ou clique fora do modal

- ✅ Grid mostra até 3 diagramas por linha

## 🎯 Casos de Uso

### Exportar Quadro para Reunião
1. Organize as tarefas no Kanban
2. Clique "Exportar PDF"
3. Compartilhe o PDF com a equipe

### Gerenciar Múltiplos Diagramas
1. Clique "Diagramas Salvos"
2. Visualize todos os diagramas de uma vez
3. Edite ou exclua conforme necessário

### Apresentar Arquitetura ao Cliente
1. Abra o diagrama salvo
2. Use modo "Visualizar" para apresentação limpa
3. Sem painéis laterais atrapalhando

## 🎨 Elementos Visuais

### Badges de Status nos Diagramas:
- 🟠 **Laranja "✏️ Editando"** = Você está editando este diagrama
- 🔵 **Azul "👁️ Visualizando"** = Você está visualizando este diagrama

### Cores dos Botões:
- 🟠 **Laranja** = Ação principal (Exportar, Novo, Editar)
- ⚪ **Branco/Cinza** = Ação secundária (Visualizar, Imprimir)
- 🔴 **Vermelho** = Ação destrutiva (Excluir)

## ❓ Perguntas Frequentes

**P: O PDF fica igual ao que vejo na tela?**  
R: Sim! A exportação captura exatamente o estado visual atual do Quadro.

**P: Posso editar um diagrama enquanto visualizo outro?**  
R: Não, você só pode ter um diagrama ativo por vez. Mas pode trocar facilmente pelo modal.

**P: O painel lateral de componentes ainda existe?**  
R: Sim! Apenas o painel de "Diagramas Salvos" virou modal. Os componentes ainda aparecem no lado esquerdo quando você está editando.

**P: Posso recuperar um diagrama excluído?**  
R: Não, a exclusão é permanente. Confirme antes de excluir!
