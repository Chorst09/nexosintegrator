## 🚀 Como Usar

### Navegação
Use o menu lateral para acessar todas as funcionalidades.

### Criar Nova Empresa
1. Acesse "Empresas"
2. Clique em "Nova Empresa"
3. Preencha os dados e contatos
4. Salve

### Criar Oportunidade
1. Acesse "Pipeline"
2. Clique em "Nova Oportunidade"
3. Selecione empresa e responsável
4. Defina valor e probabilidade
5. Arraste entre as etapas do funil

### Gerenciar Atividades
1. Acesse "Atividades"
2. Crie ligações, reuniões, tarefas
3. Defina prioridades e prazos
4. Acompanhe status

### Visualizar Relatórios
1. Acesse "Relatórios"
2. Selecione período e tipo
3. Analise KPIs e gráficos
4. Exporte dados
