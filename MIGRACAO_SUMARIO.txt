🎯 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

1. CONFIGURAR GITHUB REMOTE
   ├─ Criar repositório em https://github.com/new
   ├─ git remote add origin https://github.com/seu-usuario/crm-comercial.git
   └─ git push -u origin main

2. CLONAR NO NOVO SERVIDOR
   ├─ ssh root@SEU_IP_NOVO
   ├─ git clone https://github.com/seu-usuario/crm-comercial.git
   ├─ cd crm-comercial
   └─ chmod +x scripts/*.sh

3. SEGUIR O GUIA DE MIGRAÇÃO
   ├─ Opção A: cat GUIA_MIGRACAO_GITHUB.md (completo)
   ├─ Opção B: cat CHECKLIST_MIGRACAO_RAPIDO.md (rápido)
   └─ Opção C: cat MIGRACAO_README.md (resumo)

4. EXECUTAR SCRIPTS NA ORDEM
   ├─ ./scripts/preparar-servidor-definitivo.sh
   ├─ ./scripts/backup-completo.sh (no servidor provisório)
   ├─ ./scripts/restaurar-backup.sh ~/crm-backup-YYYYMMDD-HHMMSS
   └─ ./scripts/verificar-migracao.sh

🔐 SEGURANÇA
═══════════════════════════════════════════════════════════════════════════════

Após a migração, execute:

  1. Alterar senhas padrão
     sudo -u postgres psql -c "ALTER USER crm_user WITH PASSWORD 'senha_forte';"

  2. Configurar SSL/HTTPS
     sudo apt-get install certbot
     sudo certbot certonly --standalone -d seu-dominio.com

  3. Configurar backups automáticos
     crontab -e
     # Adicionar: 0 2 * * * /var/www/crm-comercial/scripts/backup-completo.sh

  4. Monitorar logs
     pm2 logs crm-api

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PostgreSQL não conecta
  → psql -U crm_user -h localhost -d crm_comercial -c "SELECT 1"

API não responde
  → pm2 logs crm-api --lines 50
  → pm2 restart crm-api

Porta 8081 em uso
  → netstat -tulpn | grep 8081

Frontend não carrega
  → cd /var/www/crm-comercial/apps/web && npm run build
  → pm2 restart crm-api
